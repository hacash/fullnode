# Hacash WASM/JavaScript SDK

This crate is the browser/Node.js SDK migrated from `../fullnode/sdk`. Its
product boundary remains WASM/JavaScript; the `rlib` crate type only supports
native compatibility tests and is not a separate Rust SDK API commitment.

## Compatibility

The raw wasm-bindgen API keeps the historical names:

- `create_account`, `verify_address`
- `hac_to_unit`, `hac_to_mei`
- `CoinTransferParam`, `create_coin_transfer`
- `SignTxParam`, `sign_transaction`

Explicit-timestamp Type2 HAC/SAT/HACD transfers retain the old wire bytes. A
golden test covers the hash, fee hash and fully signed body generated by the
old SDK. A zero timestamp follows the later SDK behavior and uses current Unix
time.

`chain_id` remains a reserved compatibility field. Type2 transaction encoding
has no chain-id field, so silently assigning it a new action meaning would
change transaction bytes and is intentionally avoided.

The signer uses the current standard-protocol registry and supports standard
Type1, Type2 and Type3 transactions/actions. It does not link the full-node
`app`, consensus/mining or VM composition, keeping x16rs and node-only
dependencies out of the WASM bundle. Transaction hex must be consumed exactly;
trailing bytes are rejected.

## Build

Prerequisites:

```sh
rustup target add wasm32-unknown-unknown
cargo install -f wasm-bindgen-cli --version 0.2.100
```

`wasm-opt` is optional and used automatically when installed.

Build all Node.js, web ESM and inline-page artifacts:

```sh
./sdk/pack.sh
```

Outputs are written under `sdk/dist/`:

- `nodejs/`: raw CommonJS wasm-bindgen output
- `web/`: raw browser ESM wasm-bindgen output
- `page/`: no-module, base64-inlined browser bundle
- `js/`: friendly JS compatibility layer

## JavaScript usage

CommonJS:

```js
const create_hacash_sdk = require("./sdk/dist/js/hacashsdk.cjs");

const sdk = await create_hacash_sdk();
const tx = sdk.create_coin_transfer({
    main_prikey: "123456",
    to_address: "1MzNY1oA3kfgYi75zquj3SRUPYztzXHzK9",
    fee: "1:244",
    hacash: "1:244",
    timestamp: 1755223764,
});
```

The friendly layer accepts plain objects and converts `number|string|bigint`
values for the wasm-bindgen `u64` fields `timestamp`, `satoshi` and `chain_id`.
JavaScript numbers must be safe integers; use a decimal string or `bigint` for
larger values. The raw generated API remains available as `sdk.raw`.

Smoke tests after packaging:

```sh
node ./sdk/tests/friendly_node.cjs
node ./sdk/tests/friendly_node_esm.mjs
node ./sdk/tests/friendly_page_vm.cjs
```
